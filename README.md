# ECCMaster
### Error Correction Code Strategies for SRAM Wrappers

This repository contains the implementation and supporting material for the Master's thesis:

**“Error Correction Code Strategies and Wrapper Design for Reliable SRAM”**  
Juan Camilo Ospina Sanchez  
NTNU – Norwegian University of Science and Technology (2026)

---

## 📌 Overview

This project presents a **configurable SRAM memory wrapper** designed to improve reliability against soft errors.

The work explores multiple Error Correction Code (ECC) schemes and introduces a **word-packing strategy** to reduce memory overhead.

---

## 🧠 Key Features

- Parameterizable SRAM wrapper  
- Support for multiple ECC schemes:
  - SEC–DED (Hamming)
  - BCH (Double Error Correction)
  - DMC (Decimal Matrix Code)  
- Packing strategy for area optimization  
- Formal verification using SystemVerilog Assertions (SVA)  
- Compatible with OpenRAM memory models
